# Shrines

One otherworldly shrine per world, placed by the planet POI tables as an isolated site with no road to it.

- **Carcinoma, Fountain of Life** (`WFFountainOfLife`): holds 30u of vitae (`WFVitae`) a round, which can't be
  made or bought. Draw it with any container. Ten units in the blood heal everything a rejuvenate does (damage,
  wounds, organs, lost limbs, blood, pain) through `WFLifeSurge`, which puts handcuffs back on afterwards. Less than
  a dose waits for more. The heart stops beating once the fountain is dry (`WFFountainSystem`).

The sprite is drawn by `Tools/_WF/Shrines/fountain_of_life.py`. The site map is hand-made,
`Resources/Maps/_WF/PlanetPois/carcinoma_fountain_of_life.yml`: edit it in game with `loadgrid` and `savegrid`.
