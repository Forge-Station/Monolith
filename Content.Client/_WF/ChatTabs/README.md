# ChatTabs

Tabs on every chat box, each showing its own set of channels, and a pop-out window for the chat log.

Players click a tab to switch, right-click it to rename it, pick its channels, move it or delete it, and press `+` to
add one (up to 10). The filter button beside the input line edits the selected tab too. A tab shows a count of the
messages it holds that the selected tab hides. Tabs are the same in every chat box and are saved in the client CVar
`wf.chat_tabs`; an empty value gives the defaults (All, Local, Radio, OOC).

The pop-out button at the end of the tab row moves the tabs and the log into their own OS window, for another monitor.
The input line stays in the game window, because the engine only delivers typed text to the OS window that has focus.
The floating chat box shrinks to that line; docked chat boxes (separated layout, lobby, the cockpit) show a notice
with a Dock button instead. Closing the window docks the log. The window survives a change of screen, so it stays put
between the lobby and the round. `wf.ui_window_popout` hides the button, as it does for other windows.

Entry points: `ChatTabsUIController` (the tab list, selection, unread counts, saving), `ChatTabBar` and `ChatTabPopup`
(the row and a tab's settings), `ChatLogPopoutUIController` and `ChatLogWindow` (the pop-out). `ChatBox.Tabs.cs`,
`ResizableChatBox.Tabs.cs` and `ChannelFilterPopup.Tabs.cs` are partial classes of the upstream chat controls: they
add the tab bar when a chat box enters the tree and keep the filter popup's checkboxes in step with the selected tab,
which is what the upstream chat box filters by.

Differences from upstream chat: a chat box refills from the chat history when it enters the tree or the tab changes,
so the lobby shows earlier messages; the refill is the newest 1000 lines on the tab's channels
(`ChatBox.WfRefillLimit`), since laying out a long round's history stalls the client; a chat box outside the tree no
longer receives messages; and a message's sound cue plays when it arrives if any tab shows its channel, rather than
when a filter first reveals it.
