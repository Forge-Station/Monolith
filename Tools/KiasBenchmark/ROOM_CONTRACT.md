# Дополнения пользователя от 2026-10-10

Эти решения уточняют исходный пакет v2:

- Замкнутое помещение покрывается целиком, без ограничения дальности.
- Если физическая область открыта в космос, применяется фиксированный радиус 7 от сканера. Выбираются только существующие клетки его грида, достижимые по кардинальным рёбрам, без пересечения стен и дверей. Пустой космос и соседние гриды не включаются.
- Тайл двери — общий терминальный тайл обеих прилегающих комнат. Оба подходящих сканера получают локальные показания. Общий Entities/Crew учитывает существо/серийный номер один раз.
- При посадке на экспедицию проверить комнатные и внешние датчики, переходы между гридами, ложные контакты, восстановление после взлёта. Автоматическое отключение вводится только после доказательства конкретной проблемы; произвольное отключение половины приборов не является реализацией требования.

Питание, DATA и модули проверяются независимо от геометрии. В UI показывается фактическая маска покрытия; legacy Range не редактируется.
