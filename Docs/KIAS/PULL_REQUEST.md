# KIAS: программируемая корабельная автоматика

KIAS соединяет физические карточки с графами, DATA-сеть, датчики и штатные устройства корабля. Программатор редактирует схему и записывает её на карточку; шкаф исполняет её с ограничениями очередей, таймеров и команд. Доступность определяется питанием, закреплением, DATA и установленными серверными ролями. Исключение для настройки без питания действует только на замороженной карте при маппинге.

Поддержаны конкретные устройства, выборки по помещению/группе, диагностический монитор, оптические сканеры, атмосферные и пожарные тревоги, питание, освещение, объявления, навигация и штатные исполнительные механизмы. Редактор показывает типы портов и проверяет граф до записи. Локализация и ресурсы KIAS находятся в собственных каталогах; история разработки и исходники графики перенесены в `Docs/KIAS`.

Независимое ревью исправило выполнение настоящих команд сервисным Test, невыключенные камеры после потери DATA, потерю снимков выходов при перестроении, задержки здоровых кораблей за dirty-grid, устаревшие выборки Room и кэши тревог/дефицита питания. Палитра получила серверный поиск и страницы по 256 устройств. Редактирование обновляет BUI один раз. Загрузчик физических сценариев сохраняет и проверяет угол повёрнутых fixtures.

Интеграции используют штатные события и узкие API. Специальные вызовы KIAS удалены из GunSystem и DamageableSystem; прибытие автопилота обрабатывается внутри KIAS по жизненному циклу ShipSteererComponent. Исключены 11 независимых изменений Station AI, TTS, радио и общего кода; для них сохранён отдельный восстановимый патч. Изменения RobustToolbox не требуются. Нативные интеграции помечены блоками `#Forge-change` с причиной.

Проверки: Release 188/188, Debug 188/188, Python 111/111; отдельные PowerShell проверки блокировок и логов пройдены. Интеграционные тесты запускаются последовательно из-за штатного статического аудиокэша тестовых миров. Подробности записаны в локальный `KIAS_REVIEW/07_FIXES_AND_VALIDATION.md`. Он также отделяет исправленные дефекты от прежних измерений A–B–B–A. Новый замер производительности не выполнялся; старые результаты не доказывают выигрыш после этих изменений.

Для проверки в игре: записать карточку; вызвать сервисный Test с задержанной командой и убедиться в отсутствии воздействия; оборвать DATA оптического сканера; изменить Room и проверить выборку; восстановить связь после снятия тревоги; найти устройство на второй странице; проверить прибытие и отмену автопилота. Версия программ и существующие идентификаторы прототипов сохранены.
