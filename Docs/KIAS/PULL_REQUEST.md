# KIAS: программируемая корабельная автоматика

Добавляет DATA-сеть, физические карточки с графами, программатор, шкаф исполнения, датчики и серверные роли. Автоматика управляет штатными устройствами корабля, учитывая питание, закрепление, доступность сети и права пользователя. Исключение для настройки без питания ограничено замороженной картой маппинга.

Редактор проверяет типы портов и схему до WRITE, поддерживает конкретные устройства, выборки по помещению/группе, поиск и страницы палитры. Диагностика показывает живые выходы и физические настройки устройств. Включены русская и английская локализация, игровые спрайты и документация.

Исправлены изоляция сервисного Test, отключение оптических камер при потере DATA, сохранение выходов при rebuild, очереди нескольких кораблей, обновление Room selectors, кэши питания/тревог и повторные обновления BUI. Прибытие автопилота определяется по успешному завершению штатного компонента управления; отмена не вызывает событие прибытия KIAS.

Нативные интеграции используют узкие API и штатные события, помеченные #Forge-change. Посторонние изменения Station AI/TTS/радио и отдельный engine patch исключены. В поставке отсутствуют стенд бенчмарков, запускатели, лабораторные фикстуры и профилирование времени; они сохранены в KIASDev.

Проверки производственной ветки описаны в [VALIDATION.md](VALIDATION.md). Версия программ и существующие идентификаторы прототипов сохранены.
