# Stylesheets

Wolfgate's UI skins, Wolfgate Retro (Aphelion, the default) and Wolfgate (Futurist), picked under Wolfgate UI style in the options,
each with a matching HUD theme. The rules are appended after the stock Nano/Space stylesheets, so they win on equal
specificity without forking them. The module also restyles the lobby and the character creator.

Entry points: `StyleWolfgate` (the shared rule set, with `.Creator`, `.Lobby`, `.Loadouts` and `.Rules` partials) and
`WolfgateSkin` (one skin's palette, textures, HUD theme and type). The textures under
`Resources/Textures/_WF/Stylesheets/Interface` are generated by
`Tools/_WF/Stylesheets/WolfgateUiTextures/generate_textures.py`; keep its palettes in step with `WolfgateSkin`.

The default skin is `WolfgateSkins.Default`; the `wf.ui_style` default in `WolfgateCVars` must be its id. The engine saves a
CVar only when it differs from the default, so a player who never picked a style follows the default and a saved style is
kept. A player with no HUD theme saved gets the one that pairs with their skin (`StylesheetManager` overrides the
`interface.theme` default). At launch and on every skin change a saved Wolfgate HUD theme follows the skin, so a player
who never picked a style does not get the Retro skin with the Futurist HUD; a HUD theme from elsewhere is kept.
