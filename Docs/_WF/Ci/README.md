# Ci

Repository tooling run by GitHub Actions; nothing in game.

- `modules.py` checks the module rules in `AGENTS.md` and generates the module READMEs and `Docs/_WF/NONMODULAR.md`
  (`--write`, `--check`, `--pr-check <ref>`). `modules.yml` lists the modules outside `_WF` and the edits that can't
  hold a marker. `.github/workflows/wf-modules.yml` runs it on every pull request.
- `test_merge.py` merges the pull requests given to a manual publish run onto the checkout before packaging, and
  records the result in `Resources/Symphony/testmerges.json` and the build's version suffix.
- `actions_discord_pr_notify.py` posts a Discord embed when a pull request is opened, reopened, marked ready, merged
  or closed (`.github/workflows/discord-pr-notify.yml`).

Its marked edits are the publish workflows and the separate Wolfgate changelog (`Resources/Changelog/Wolfgate.yml`,
entry ids from 100000).
