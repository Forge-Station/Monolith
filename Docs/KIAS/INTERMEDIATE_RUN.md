# Полный промежуточный ABBA

FULL GAME FINAL RUN NOT YET EXECUTED.

По указанию владельца готовится полный промежуточный тест текущего состояния. Это настоящий FullGame-сценарий с проверками игровых результатов, но не завершённая сертификация исходного v3.

Запуск: `D:\Workspace\ss14_lua\corvax\Monolith\Run_KIAS_Intermediate_Tests.bat`. После открытия окно ждёт `START`; `EXIT` закрывает его без сборки и тестов. Перед START закрыть игру и лишние приложения; не менять ветку и исходники до завершения.

По умолчанию: 40 Briar, A–B–B–A, 60 TPS, каждый прогон — 10800 тиков прогрева и 108000 тиков измерения (3 + 30 минут симуляции), до четырёх настоящих сетевых клиентов. Чистая серия — 132 минуты симуляции; реальные сборки, gate, игровые проверки A/B, загрузка карт и замедление сервера добавляют время. Для ночного запуска разумно оставить несколько часов. ETA уточняется по фактическому продвижению, затем по завершённым прогонам.

После START автоматически выполняются:

1. Проверка окружения и блокировки второго запуска.
2. Свежие сопоставимые Release-серверы и клиенты A/B с хешами исходников, движка и карты.
3. Тесты инструментов, Release-регрессия без пропусков, все 27 физических программ.
4. Настоящие игровые проверки A/B: экипаж, DATA/питание, оружие, вентиляция, пожар, ПКО, столкновения, мир/FTL/навигация и составные воздействия.
5. Полная промежуточная серия с синхронными волнами на 40 кораблях, независимыми фоновыми событиями, postconditions, контролем очередей, faults и ошибок сервера/клиентов.
6. Проверяемые отчёты и архив для анализа. Отказ любого обязательного этапа прерывает серию с FAILED_INCOMPLETE и сохраняет доступные доказательства.

Результаты: отдельный каталог `.kias-benchmark/rerun/<дата-id>/`, указатель `.kias-benchmark/CURRENT_RUN.txt`. Главные файлы: `detailed.log`, `launcher-status.json`, `launcher-stage.json`, `preflight-policy.json`, `series/status.json`, `series/report.html`, `series/results.json`, `runs/1-A` … `runs/4-A`, итоговый `KIAS_web-agent.zip`. Старые результаты не перезаписываются. Успех — код 0 и ABBA_COMPLETE; отказ — ненулевой код и FAILED_INCOMPLETE.

Режим явно выбирает `-EssentialPreflight`. Строгий `Run_KIAS_Tests.bat -CheckOnly` продолжает проверять весь v3 и может возвращать NOT_READY; это не проверка возможности промежуточного запуска. Основной BAT сохраняет строгий режим по умолчанию.

Отложенные по решению владельца радиация, лампы, отдельное повреждение конструкций, стыковка и исчерпание конечного магазина перечислены в `Tools/KiasBenchmark/DEFERRED_CHECKS.md`. Совместимость восьми актуальных корпусов с питанием, программой и восстановлением DATA проверена отдельно; полноценный смешанный боевой флот этим не подтверждён. Другие открытые требования: полная калибровка Physics, сравнение CPU/TPS до/после на свободной машине и ручная игровая приёмка UI. Они не получают PASS от промежуточной серии. Подробности: `Docs/KIAS/REMAINING_BENCHMARK_WORK.md`.

## Подготовка к ночному запуску

Использовать именно `Run_KIAS_Intermediate_Tests.bat`, затем в его окне ввести `START`. Обычный `Run_KIAS_Tests.bat` остаётся строгим и остановится на незавершённой сертификации v3. Промежуточный BAT выполняет настоящий длинный ABBA, но не присваивает пропущенным требованиям PASS.

Пока окно ждёт START, сборки, удаление результатов и тесты не выполняются. Можно ввести EXIT. После START исходники и ветку не менять; компьютер должен оставаться включённым без перехода в сон. Окончание оставляет окно открытым. Смотреть итоговый статус и путь архива; при ошибке сохранить архив целиком, включая журнал отказавшего этапа. Архив содержит `ARCHIVE_SHA256.json` для проверки целостности вложенных файлов.

Последняя подготовка сохраняется отдельно в `.kias-benchmark/v3/night-preflight65/`; она не является результатом ночной серии. Ночной запуск всегда создаёт новый каталог и свежие сопоставимые сборки.
