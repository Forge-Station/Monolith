# TypingBubble

Every character picks the bubble shown over them while they type, in the Typing bubble picker of the character
creator's Body card (`Content.Client/_WF/TypingBubble/HumanoidProfileEditor.TypingBubble.cs`): one animated box per
`typingIndicator` prototype, the species' own first. `empty` (no art) and `thaven` (the plain art with a Thaven offset)
are not offered (`WFTypingBubbleRules`).

The profile stores the pick as `TypingIndicator` (`HumanoidCharacterProfile.TypingBubble.cs`, database column
`typing_indicator`), null for the species' own; validation drops an unknown or hidden one. When a profile is loaded
onto a mob, `WFTypingBubbleSystem` gives it `WFTypingBubbleComponent`, or takes it off for the species' own. The
client's `TypingIndicatorVisualizerSystem` draws that bubble in place of the species' (a marked edit); clothing that
changes the bubble still wins. The picked bubble keeps its own offset.
