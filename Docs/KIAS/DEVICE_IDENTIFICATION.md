# Выбор устройств и диагностика KIAS

У каждого устройства есть сохраняемый идентификатор из 12 шестнадцатеричных символов. Он назначается один раз при запуске компонента; загрузка копии с уже занятым идентификатором получает новый. В каталоге «Конкретные устройства» первой строкой показано название, второй — короткий уникальный префикс ID и профиль. Префикс начинается с шести символов и удлиняется при совпадениях, включая ID закреплённых отключённых устройств того же грида. Полный ID доступен в подсказке, поиске, диагностике и сообщении мультитула. Привязки программ продолжают использовать сериализуемую ссылку на сущность, а не имя или идентификатор.

Список разделён на сворачиваемые помещения. Названные помещения идут первыми по алфавиту, неназванные — по номеру. Поиск учитывает помещение, название, идентификатор и профиль устройства. Для автоматического разделения используются тайлы пола и закреплённые герметичные перегородки, включая двери независимо от текущего открытия. Это геометрическая группировка для выбора, а не симуляция атмосферы. Расчёт ограничен 16384 шагами и кешируется на две секунды; он не выполняется каждый кадр. Номера помещений могут измениться при изменении планировки или набора устройств; идентификаторы устройств сохраняются.

Режим «Диагностика» открывает цепочку подключения, состояние питания и текущие выходы выбранного устройства. Значения обновляются раз в секунду из существующего кеша графовых выходов. Отключённые устройства не показывают старые значения. Отдельный пункт «Мониторинг» убран из меню; старое числовое значение режима сохраняется совместимым.

Для поворотного выключателя доступны 2–4 положения и выбор одного из четырёх существующих выходов для каждого положения. Разные положения могут выдавать одинаковый сигнал. Настройки сохраняются в компоненте. Сервер проверяет диапазоны, право владельца и доступность устройства на расстоянии взаимодействия.

Из диагностики также можно менять дальность сканеров и датчиков. Применяются те же пределы, что в их обычных окнах настройки; имя помещения и другие параметры при изменении дальности не сбрасываются.

## Размеры и установка

| Объекты | Масштаб относительно предыдущего патча |
| --- | --- |
| Модули сканера на полу | 70% |
| Программируемая схема, картридж пожаротушения | 75% |
| Комплект интеграции | 60%, ещё на 20% меньше прежних 75% |
| Мастер-ключ, ключевой и поворотный выключатели | 50% |
| Динамик, обычный и продвинутый сканеры | 65%, новый компактный настенный корпус |
| Пожаротушение | 75%, новый настенный корпус |
| Кнопка тревоги | 55% |

Размеры кадров остаются 32×32; консоль и программатор остаются 64×32, ядро — 32×64. Масштаб предмета на полу не меняет его размер в инвентаре. Настенные приборы смещены к краю стены, корпус направлен от крепления. [Примерка на стене](WALL_DEVICE_PREVIEW.png) показывает экспортированные пиксели с ближайшим соседним масштабированием.

Настенные и направленные приборы допускают выбор направления до закрепления. `Transform.noRot: false` разрешает поворот объекта, `Sprite.noRot: false` сохраняет направление относительно мира при изменении камеры. Поворот закреплённого устройства запрещён штатным `Rotatable`. Стационарные серверы, ядро и двухтайловые консоли сохраняют фиксированную ориентацию. [Аудит прототипов](DEVICE_ROTATION_AUDIT.json).

DATA-кабель использует геометрию штатного среднего силового кабеля с отдельным цветом и состояниями `data_0`–`data_15`. Маска соседей вычисляется при перестроении DATA-топологии, включая отключённую сеть; отображение использует штатный `CableVisualizer`. Силовые сети и NodeContainer к DATA не добавляются. Автор исходного кабеля — MIXnikita для SS220, CC-BY-SA-3.0, указан в RSI metadata.

Новые настенные рисунки созданы встроенным OpenAI imagegen; окончательные промпты находятся в [SPRITE_PROMPTS.json](SPRITE_PROMPTS.json). Кредит Hurtsay относится к его оригинальным ресурсам и не переносится на новые изображения.
