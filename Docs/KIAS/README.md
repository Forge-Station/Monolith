# KIAS — корабельная автоматика

KIAS соединяет физические карточки с графами, DATA-сеть, датчики и штатные устройства корабля. Рабочая ветка разработки и лаборатория находятся в KIASDev; KIAS содержит готовые игровые изменения и их регрессионные тесты.

Сервисный Test проверяет копию состояния графа: настоящие команды и таймеры не запускаются, рабочая автоматика продолжает исполняться. Палитра устройств поддерживает поиск и страницы по 256 записей. Потеря DATA отключает оптическую камеру; перестроение сохраняет валидные несигнальные выходы прежних устройств того же грида.

Настройка без питания разрешена только активному администратору Mapping на неинициализированной замороженной карте. Обычные и инициализированные карты остаются ограничены питанием. Название системы — KIAS на обоих языках.
