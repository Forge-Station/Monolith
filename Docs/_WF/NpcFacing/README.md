# NpcFacing

Mindless zombies turn to face where they walk and whom they hit. `ZombifyEntity` turns combat mode on before it
gives the body an HTN brain, and combat mode hands any body it can't tell is an NPC a `MouseRotator` and
`NoRotateOnMove`. With no player to aim the mouse the zombie never turned: it walked, sidestepped and swung while
still looking south. The marked edit in `ZombieSystem.Transform.cs` drops both components from a zombie that rises
without a mind. Strangers and crew get their HTN at spawn, so they were never affected. `NpcFacingTest` covers
zombies on approach and in melee, and a stranger and a crewman sent walking.
